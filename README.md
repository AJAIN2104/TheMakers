# The Makers — React Website

## Structure
- `src/components/` — reusable UI components grouped by feature
- `src/pages/` — route-level pages
- `src/data/` — editable school and Instagram data
- `public/images/` — website images
- `src/styles/` — global styling

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Edit Instagram
Open `src/data/siteData.js` and replace `instagramPosts` URLs with your real Instagram profile/post URLs.

## Edit schools
Open `src/data/siteData.js` and update the `schools` array. Verify every school name before publishing it as a work-experience claim.
